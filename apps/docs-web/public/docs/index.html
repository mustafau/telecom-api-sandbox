What the responses mean

        

          Contract mode serves fixed, schema checked examples. POST, PATCH, PUT, and DELETE return
          immutable mock results and do not persist changes. A contract mock does not simulate
          business workflows or deliver notifications.
        

        

          Each API uses its own context path. Missing v5 contexts use reviewed v4 paths or
          documented sandbox conventions. The downloadable specs show these routing overrides.
        

        

          Generic detail routes return an example for any path ID. Seeded scenarios list their
          supported IDs separately. Query support is limited to declared offset and limit
          pagination. Other query behavior returns an explicit error. Public requests require no
          authentication.
        

        

          Exact upstream versions, unavailable pairs, schema exceptions, and responses without
          schemas appear in the coverage report. Source specifications may contain original licensed
          upstream examples; demo scenarios use synthetic data.
