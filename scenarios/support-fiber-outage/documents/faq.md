# Demonstration FAQ

**Why is my connection unavailable?** In this fictional case, a fiber cut affects the access resource used by the customer's service.

**When will it return?** The fixed scenario estimate is 2026-10-22 14:00 UTC. It is demonstration data, not a live operational estimate.

**Can the agent create another ticket?** Public POST requests return fixed contract examples. They do not persist new tickets. Private writable sandboxes have not been implemented.

**How do I index this material?** Index the three original scenario documents in your own retrieval system. Follow the calls in `/scenarios/support-fiber-outage` for structured records. Check the coverage report before assuming another API or version exists.
